
# **Веб-приложение для автоматического и ручного регулирования температуры теплоносителя в котельной с использованием ПИД-регулятора и погодозависимого температурного графика.**

#**Система предназначена для управления тепловыми процессами в котельной. Она позволяет:**

1.Настраивать коэффициенты ПИД-регулятора (пропорциональный, интегральный, дифференциальный).

2.Задавать погодозависимый температурный график (зависимость уставки температуры теплоносителя от наружной температуры).

3.Работать в автоматическом режиме (ПИД-регулирование) или ручном (принудительная установка сигнала на клапан).

4.Вести журнал управления с фиксацией всех параметров (ошибка, составляющие ПИД, выходной сигнал).

5.Отслеживать аварийные события (превышение температуры, неисправность датчиков) и подтверждать их.

6.Получать сводную статистику за последние часы.

7.Взаимодействовать через веб-интерфейс или REST API.

#**Возможности**
1.ПИД-регулирование с защитой от насыщения интегратора (anti-windup).

2.Погодозависимый график: линейная интерполяция между двумя опорными точками.

3.Режимы управления: AUTO (автоматический) и MANUAL (ручной).

4.Журналирование всех циклов управления и аварий.

5.Веб-интерфейс на основе Jinja2 для удобного мониторинга и настройки.

6.REST API для интеграции с внешними системами.

7.Хранение данных в SQLite .

#**Технологии**
Python 3.11+

FastAPI – веб-фреймворк

SQLAlchemy – ORM

SQLite 

Pydantic – валидация данных

Jinja2 – шаблонизатор

Uvicorn – ASGI-сервер

Docker (опционально)

#**Установка и запуск:**
Локальный запуск
Клонируйте репозиторий и перейдите в папку проекта.

**Создайте виртуальное окружение и активируйте его:**

    python -m venv venv
    source venv/bin/activate  # для Linux/Mac
    venv\Scripts\activate     # для Windows
**Установите зависимости:**

    pip install -r requirements.txt
**Если файла requirements.txt нет, установите вручную:**

    pip install fastapi uvicorn sqlalchemy pydantic python-multipart aiofiles jinja2
**Инициализируйте базу данных и загрузите демонстрационные настройки:**

    python scripts/init_demo_data.py
**Запустите сервер:**

    uvicorn app.main:app --host 0.0.0.0 --port 8001
**Откройте браузер по адресу http://localhost:8001.**


REST API
Документация доступна по адресу /docs (Swagger UI). Основные эндпоинты:

GET /api/health – проверка работоспособности.

GET /api/pid-settings – получение текущих настроек ПИД.

POST /api/pid-settings – обновление настроек.

GET /api/temperature-graph – получение текущего графика.

POST /api/temperature-graph – обновление графика.

POST /api/control/execute – выполнить цикл управления (передать t_out, t_current, dt).

GET /api/control/mode – текущий режим и ручной выход.

POST /api/control/mode/{mode} – установить режим (AUTO/MANUAL).

POST /api/control/manual – установить выходной сигнал в ручном режиме.

GET /api/control/history – последние записи журнала.

GET /api/control/batch-summary – сводка за указанный период (часы).

GET /api/alarms – аварийные события.

POST /api/alarms/{id}/acknowledge – подтвердить аварию.
